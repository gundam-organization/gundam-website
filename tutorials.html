Start Here

Follow the examples in sequence

The tutorial repository is designed as a progressive learning path. Use the website for orientation and follow the linked repository guides for commands, file contents, and exercises.

  1. Prepare the environment.
    Install GUNDAM, clone the tutorial repository, and use its environment helper to make ROOT and gundamFitter available.
  2. Generate the shared mock dataset.
    All tutorial levels use the same reproducible ROOT input so the examples can focus on configuration changes.
  3. Complete the basic and extended examples.
    Build from dataset loading and event selection to normalization parameters, correlated uncertainties, response dials, and interpolation choices.
  4. Study the modular example.
    See how a larger analysis separates datasets, samples, parameters, plots, overrides, and the top-level fitter configuration.

Input Examples

One dataset, several learning levels

The repository supplies a mock ROOT dataset generator used by every basic, extended, and advanced example. The generated event tree contains example kinematic quantities, reaction and selection categories, event weights, and response functions for systematic parameters.

Using one shared input makes it easier to see how changes in selections, parameters, covariance information, and interpolation methods affect the configured analysis.

Configuration

Progress from flat to modular inputs

The introductory packages keep each example self-contained: configuration files sit beside the small binning, selection, parameter, and covariance inputs they use. This makes individual concepts easy to isolate.

The advanced package demonstrates a production-style layout. A single top-level configuration references separate files for datasets, samples, parameters, plots, and optional overrides.

Fit Diagnostics

Study parameter response and correlations

The extended examples show how a fit changes when it contains multiple selections, binned normalization parameters, correlated parameters driven by a covariance matrix, and event-by-event response functions.

A dedicated comparison applies natural-spline, not-a-knot spline, and piecewise-linear graph interpolation to the same deliberately non-smooth response. The repository includes plotting tools for examining these differences.
