Versioning

Keep software and configuration compatible

Configuration can declare minGundamVersion. GUNDAM stops when the active installation is older than that declared minimum, preventing a job from silently running without required behavior.

A complete analysis record should include the GUNDAM version, submodule state, ROOT version, compiler, configuration, inputs, and exact execution command.

Upgrade Guidance

Validate before adopting a new version

  1. Read release notes.
    Identify changes affecting configuration, numerical behavior, dependencies, or output.
  2. Build separately.
    Keep the validated installation available while testing the new release.
  3. Run a reference suite.
    Compare nominal, fit, uncertainty, and diagnostic outputs against an approved baseline.
  4. Record the transition.
    Document expected differences before using the new release for production results.
