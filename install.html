Quick Start

Clone a complete working tree

Clone the official repository recursively so all required submodules are present:

cd "$REPO_DIR"
git clone --recurse-submodules https://github.com/gundam-organization/gundam.git
cd gundam
./update.sh --latest

Recommended: Use the latest tagged release for analysis work. Running ./update.sh --latest selects that release and updates its submodules.

Standard Build

Configure, compile, and install

GUNDAM follows a conventional CMake workflow. The exact options depend on your ROOT installation and target system.

export REPO_DIR="$HOME/Repositories"
export BUILD_DIR="$HOME/Build"
export INSTALL_DIR="$HOME/Install"

mkdir -p "$REPO_DIR" "$BUILD_DIR" "$INSTALL_DIR"
cd "$BUILD_DIR"

cmake -S "$REPO_DIR/gundam" \
      -B "$BUILD_DIR/gundam" \
      -DCMAKE_INSTALL_PREFIX="$INSTALL_DIR/gundam"

cmake --build "$BUILD_DIR/gundam" --parallel
cmake --install "$BUILD_DIR/gundam"

After installation, configure your shell environment:

source "$INSTALL_DIR/gundam/setup.sh"

Development Setup

Use the project development helpers

The repository includes a setup optimized for maintaining multiple builds or feature branches:

cd "$REPO_DIR/gundam"
source "$ROOTSYS/bin/thisroot.sh"
source ./cmake/scripts/gundam-setup.sh
gundam-build

This defines GUNDAM_ROOT and a machine-specific GUNDAM_TARGET. You can override build and install locations with GUNDAM_BUILD and GUNDAM_INSTALL, and set build parallelism with GUNDAM_JOBS.

Troubleshooting

Common installation checks

  • Confirm that root-config --cflags reports a C++ standard compatible with the GUNDAM build.
  • Run git submodule update --init --recursive if a dependency directory is missing.
  • Delete only the affected build directory—not the source tree—before retrying a clean CMake configure.
  • Include the compiler, ROOT version, CMake command, and complete error output when opening an issue.
