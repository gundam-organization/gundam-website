# GUNDAM documentation sources

Each Markdown file here is one scrollable page of the website's
**Documentation** menu (`documentation.html?page=<id>`). The pages are rendered
in the browser by `assets/js/docs.js`, so editing a file and pushing to `main`
is enough to update the site.

## How a page is structured

- `#` is the page title (one per file).
- `##` headings are the **sub-sections** and `###` headings are the
  **sub-sub-sections**. The "On this page" bar on the right lists both levels.
  Deeper headings (`####` and below) show in the text only.
- To link to another page, use its file name plus the heading anchor, as you
  would on GitHub, for example `[Propagator](configuration.md#propagator-configuration)`.
  The anchor is the heading text in lower case, with punctuation removed and
  spaces turned into `-`.
- Put any images in a `docs/images/` folder and reference them as `images/<file>`.

## Adding or reordering pages

Pages and their order in the left bar come from `manifest.json`. To add a
page, create `<name>.md` here and add an entry with a unique `id`, the `file`
name, a `title`, and a one-line `description` to one of the groups.

The documentation home page (`documentation.html` without `?page=`) is an
introduction with a short paragraph about each chapter. It is plain HTML, so
when you add, rename or remove a chapter, update its entry in the
`docs-chapters` lists in `documentation.html` as well.

## Local preview

Run `npm run dev` from the repository root and open
<http://localhost:4173/documentation.html>. Opening the HTML file directly from
disk does not work, because browsers block `fetch()` on `file://` pages.

## Code reference (Doxygen)

The **Code Reference** part of the documentation (`api/`) is not written here.
It is generated by Doxygen from the comments in the GUNDAM source code, using
the configuration in the GUNDAM repository (`docs/doxygen/Doxyfile`). Only the
generated HTML is published; nothing generated is committed to either
repository.

- `.github/workflows/pages.yml` checks out the GUNDAM repository next to this
  one and runs `scripts/build-api-docs.sh`, which writes the HTML into
  `_site/api` before the site is deployed.
- The site is rebuilt on every push here, every night, when the GUNDAM
  repository sends a `gundam-code-updated` event, and on demand from the
  Actions tab ("Run workflow"), where you can also pick another GUNDAM
  repository or branch to preview.
- `api-docs/` holds the website-only settings: logo, colours, extra CSS, and
  the placeholder page used when the GUNDAM branch has no Doxyfile yet.

To preview it locally, install Doxygen and Graphviz, clone GUNDAM next to this
repository (`../gundam`), then run `npm run api-docs` followed by `npm run dev`
and open <http://localhost:4173/api/index.html>. The `api/` folder is ignored by
git.
